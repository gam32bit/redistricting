How this works

This tool was built with AI assistance. The page, the pipeline that produced its data, and some of the wording you're reading were developed with help from Claude Code. AI can make mistakes, so nothing here depends on it having read or interpreted the survey. Every response shown is lifted verbatim from the Division's published PDF by script — nothing is hand-entered, and no comment is summarized, paraphrased or ranked. One real extraction fault was found and fixed: the PDF's embedded font maps f, ff, fi and fl to unused codepoints, so every extractor silently drops them, turning "Lafayette" into "La ayette." Those glyphs are restored from an explicit replacement map, and the text was checked to leave no unmapped codepoints behind. The export's duplicated question groups — where the Division's file repeats one answer under several questions — were detected and collapsed rather than counted twice. Where it matters, check any response against the source PDF linked at the foot of this page; it is the authority, not this page.

Search is literal. Typing bus finds the exact letters b-u-s, case-insensitively, with accents folded (Más matches mas). It also matches inside words — bus hits buses and business — so a longer search word is a narrower one. There is no stemming, no synonyms, no relevance ranking, and no AI: the same query always returns the same rows, in survey order, and "Every mention" shows all of them so you can count them yourself.

Who answered. This was an open, self-selected survey, not a representative sample. The survey's intake form did not require participants to verify that they live within WJCC, and nothing prevented the same person from completing the survey more than once.

Source: Redacted Redistricting Survey Raw Results, Williamsburg–James City County Schools, June 2026 (3,106 pages). CSV and JSON reflect the filters currently applied; the PDF is the Division's complete original.
