# WJCC redistricting survey

Tools for reading the Williamsburg–James City County Schools redistricting survey, which
the division published in June 2026 as a 3,106-page PDF of 1,540 responses.

**Live search page: <https://redistricting.jwcaterine.com/>**

Source document, published by the division:

<https://wjccschools.org/wp-content/uploads/2026/06/Redacted-Redistricting-Survey-Raw-Results-Final-June-2026.pdf>

Every number produced here traces back to that PDF. Nothing is hand-entered, and no
response is summarized, paraphrased or ranked — the search page does plain
case-insensitive substring matching, so the same query always returns the same rows.
The page's own "How this works" section documents its methodology and limits, including
that this was an open, self-selected survey rather than a representative sample.

## Pipeline

Download the PDF to the repo root, then run in order from here:

```
Redacted-Redistricting-Survey-Raw-Results-Final-June-2026.pdf   (3,106 pages)
  │
  ├─ extract_clean.py   → survey_clean.txt      6,029,114 chars, 1,540 records
  ├─ parse_clean.py     → records_clean.json    1,540 records × 21 fields
  ├─ build_corpus.py    → site/comments.json    the public corpus
  │                       site/comments.csv
  ├─ build_pages.py     → docs/                 the GitHub Pages site
  └─ build_site.py      → site/explorer.build.html   standalone, corpus inlined
```

`extract_clean.py` exists because the PDF's embedded font maps `f`, `ff`, `fi` and `fl` to
unused codepoints, so every extractor silently drops them — a naive extraction reads
"La ayette" for "Lafayette." See [site/README.md](site/README.md) for the full pipeline
notes and the division's export artifacts.

## What isn't in this repo, and why

The four intermediate extracts (`survey_raw.txt`, `survey_clean.txt`, `records.json`,
`records_clean.json`) are gitignored. They hold the complete parse, including two fields
the public corpus deliberately excludes: the contact-details box, whose redactions leave
location-identifying gaps, and a staff workplace field that names one individual's school.
Both sit inside the division's published PDF already, but publishing them as structured
JSON is a practical difference, so they stay out. Regenerate them from the PDF with the
first two scripts above.

The 9.3 MB source PDF is also gitignored — the division hosts it, and git history is
permanent.
